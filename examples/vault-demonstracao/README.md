# Vault de demonstração

Abra esta pasta pelo botão **Abrir vault** do Folio. Ela foi feita para
percorrer o produto sem depender de dados privados ou de um índice local
pré-gerado.

## Roteiro sugerido

1. Abra `artigos/artigo-abnt.md` e use **Preview**, **Problemas**, a busca e
   a biblioteca de referências.
2. Compare os mesmos temas em `artigo-numerico.md`, `artigo-apa.md` e
   `artigo-web.md`; cada arquivo declara seu próprio profile.
3. Abra `tcc/index.md` para ver transclusão de capítulos, elementos de TCC e
   sumário paginado no PDF.
4. Abra `pesquisa/projeto.md`, `notas/fichamento-silva.md` e o Canvas para
   explorar relações entre evidências e escrita.
5. Em **Views acadêmicas**, veja as views salvas em `.academic/views`; no
   **Canvas**, veja o mapa argumentativo salvo em `.academic/canvases`.

## Recursos demonstrados

- perfis ABNT autor-data e numérico, APA 7 e Web Article;
- metadados, citações, bibliografia BibTeX, backlinks e links internos;
- figura SVG, tabela, código, equação e referência cruzada;
- TCC modular por transclusão, fichamento e projeto de pesquisa;
- canvas, views e dashboard como dados operacionais locais.

Os nomes, instituições e resultados são fictícios e servem apenas de exemplo.
