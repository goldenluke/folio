# ADR 0070 — Relações e rollups acadêmicos derivados

**Status:** aceito · 2026-09-09

Relações inicialmente representam somente vínculos já conhecidos pelo domínio.
Rollups, grupos, gráficos e blocos de dashboard são projeções determinísticas
dessas relações. Fórmulas aceitam apenas aritmética numérica restrita, sem
`eval`, rede ou código arbitrário. Nenhum contador, total ou gráfico se torna
campo canônico de uma referência, documento ou projeto.
