# ADR 0073 — Consistência do workspace acadêmico

**Status:** aceito · 2026-09-09

A navegação agrupa superfícies sem fundir suas identidades. Menus contextual e
drag-and-drop delegam para Command Registry e operações semânticas permitidas;
views nunca recebem itens por drop porque são projeções. Peek e recência usam
uma representação transversal limitada. Toda superfície nova deve cumprir a
auditoria AA de teclado, foco, carregamento, erro, vazio, confirmação,
drag-and-drop, menu contextual e preview.
